# Sorteio de Números em Python

Um programa simples em Python que sorteia números aleatórios, mostra os números pares e calcula a soma deles.

## O que ele faz

* Sorteia 5 números aleatórios de 1 a 10.
* Armazena os números em uma lista.
* Mostra os números sorteados.
* Identifica os números pares.
* Soma os números pares.

## Exemplo

```text
os valores sorteados foram: 3 8 2 7 10
os valores pares foram: 8 2 10
o total somado foi 20
```

## Conceitos utilizados

* Funções
* Listas
* `for`
* `if`
* `append()`
* `randint()`
* Operador `%`
* Variáveis

## Objetivo

Projeto criado para praticar listas, funções, estruturas de repetição e números aleatórios em Python.

## Como executar

Tenha o Python instalado e execute o arquivo:

```bash
python sorteio.py
```

Projeto desenvolvido para fins de estudo.
