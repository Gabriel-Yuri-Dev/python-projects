# Verificador de Voto em Python

Um programa simples em Python que verifica se uma pessoa pode votar e se o voto é obrigatório ou opcional de acordo com sua idade.

## O que ele faz

 Calcula a idade a partir do ano de nascimento.
 Verifica se a pessoa pode votar.
 Informa se o voto é obrigatório ou opcional.
 Possui uma função `voto()`.
 Possui documentação na função através de `docstring`.

## Exemplo

```python
voto(2008)
```

Saída

```text
Quem nasceu em 2008 tem 18 anos e o voto é obrigatório.
```

Também é possível informar o ano de nascimento pelo terminal.
